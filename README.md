# 09412214 ปฏิบัติการฟิสิกส์ประยุกต์ (Applied Physics Laboratory)

เว็บไซต์รายวิชา **09412214 ปฏิบัติการฟิสิกส์ประยุกต์** มหาวิทยาลัยเทคโนโลยีราชมงคลธัญบุรี ที่เชื่อมข้อมูลอัตโนมัติจาก Google Sheet ทั้ง 7 ชีต (`Home`, `Instructors`, `Outcomes`, `Assessment`, `Grading`, `Schedule`, `Group`)

## รายการไฟล์ทั้งหมด
- `index.html` — โครงสร้างหลักของหน้าเว็บไซต์
- `styles.css` — รูปแบบการแสดงผลและโทนสีสว่าง (ขาว-ฟ้า-น้ำเงิน) รองรับทั้งคอมพิวเตอร์และมือถือ
- `app.js` — ระบบดึงข้อมูลล่าสุดจาก Google Sheet อัตโนมัติทุกครั้งที่เปิดหรือรีเฟรชหน้าเว็บ
- `banner.png` — ภาพแบนเนอร์ส่วนหัวของเว็บไซต์ (โทนสว่างแบบข้อความล้วน)
- `README.md` — คู่มือการนำขึ้น GitHub Pages

## วิธีนำขึ้นใช้งานบน GitHub Pages
1. แตกไฟล์ `.zip` ออกมาจะได้ไฟล์ทั้ง 5 ไฟล์
2. สร้าง Repository ใหม่บน GitHub (ตั้งค่าเป็น **Public**) เช่น `rmutt-09412214`
3. กด **Add file > Upload files** แล้วลากไฟล์ทั้งหมด (`index.html`, `styles.css`, `app.js`, `banner.png`, `README.md`) วางในหน้าหลักของ Repository จากนั้นกด **Commit changes**
4. ไปที่แท็บ **Settings** > เมนูด้านซ้ายเลือก **Pages**
5. ตรงหัวข้อ **Build and deployment** > **Branch** ให้เลือก `main` และโฟลเดอร์ `/ (root)` แล้วกด **Save**
6. รอประมาณ 1–2 นาที เว็บไซต์จะพร้อมใช้งานที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ-repository>/`

## ข้อควรทราบสำหรับการอัปเดตข้อมูลบน Google Sheet
- ตั้งค่าการแชร์ Google Sheet เป็น **ทุกคนที่มีลิงก์สามารถดูได้ (Anyone with the link - Viewer)**
- ห้ามเปลี่ยนชื่อแท็บทั้ง 7 ชีต (`Home`, `Instructors`, `Outcomes`, `Assessment`, `Grading`, `Schedule`, `Group`)
- **ข้อแนะนำเพิ่มเติมสำหรับชีต `Schedule`:** หากต้องการแก้ไขวันที่สอบกลางภาค/ปลายภาคในคอลัมน์ A แล้วให้เว็บไซต์อัปเดตตามทันที แนะนำให้จัดรูปแบบคอลัมน์ A ในชีต `Schedule` เป็น **ข้อความธรรมดา (Format > Number > Plain text)** เพื่อป้องกันไม่ให้ Google Sheets แปลงข้อความในคอลัมน์ตัวเลขเป็นค่าว่าง
